mdpad — 使用说明 / Notes
===========================

macOS Markdown 写作台，版本 1.1.3。
A macOS Markdown desk. Version 1.1.3.

安装 / Install
--------------
1. 把左边的 mdpad 拖到右边的「应用程序」文件夹。
   Drag mdpad on the left into the Applications folder on the right.
2. 第一次打开：在「应用程序」里右键 mdpad → 打开 → 再点「打开」。
   First launch: in Applications, right-click mdpad → Open → Open again.

   应用没有买苹果公证。右键没有「打开」时：
   系统设置 → 隐私与安全性 → 拉到底 → 仍要打开。
   The app is not notarized. If Open is missing from the menu:
   System Settings → Privacy & Security → Open Anyway.

   从 AirDrop 或聊天软件拷过来后若提示「已损坏」，在终端执行一次：
   If it says the app is damaged after AirDrop or a chat transfer, run once:
   xattr -cr /Applications/mdpad.app

快捷键 / Shortcuts
------------------
⌘N           新建 / New
⌘O           打开 / Open
⌘S           保存 / Save
⇧⌘S          另存为 / Save As
⌘F           查找 / Find
⌘1 / ⌘2 / ⌘3 源码 / 分栏 / 预览    Source / Split / Preview
⌘J           AI 对话 / AI chat
⌘,           AI 设置 / AI settings
⇧⌘F          专注模式 / Focus mode

也可以把 .md 文件拖进窗口。
You can also drop a .md file onto the window.

更新 / Updates
--------------
mdpad 菜单 → 检查更新。从 1.1.3 起，主窗口可以检查、下载并安装签名更新，装完自动重启。
已经装了 1.1.2 或更早版本的，先从发布页装一次 1.1.3。

mdpad menu → 检查更新. From 1.1.3 the main window can check, download, and install a signed update, then relaunch.
If you already have 1.1.2 or earlier, install 1.1.3 once from the release page.

数据放在哪里 / Where data lives
-------------------------------
稿子只在你保存的路径上。
崩溃快照、最近文件、AI 的接口地址和日志在：
~/Library/Application Support/mdpad
API Key 在 macOS 钥匙串，服务名 com.yirongcao.mdpad。

The document stays at the path you save.
Crash snapshots, recent files, AI endpoints, and the log:
~/Library/Application Support/mdpad
API keys are in the macOS Keychain, service com.yirongcao.mdpad.

卸载 / Uninstall
----------------
把 mdpad 从「应用程序」拖到废纸篓。
要连数据一起删，再删掉上面的 Application Support 目录，并在钥匙串访问中删掉 com.yirongcao.mdpad。

Drag mdpad from Applications to the Trash.
To delete its data too, remove the Application Support folder above and the com.yirongcao.mdpad Keychain item.
